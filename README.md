# Local Music Player — Kotlin V2.0 Modern Edition

A native Android local music player built with Kotlin, Media3/ExoPlayer, and a modern dark UI.

## Features
- Native Kotlin Android app — no HTML/WebView
- Modern dark premium player interface
- Local folder picker using Android Storage Access Framework
- MP3, M4A, WAV, FLAC, OGG, Opus and AAC detection
- Media3/ExoPlayer playback
- Play/pause, previous/next and seeking
- Volume control
- Sleep timer
- MediaSession notification and lock-screen controls
- Persistent selected music library
- Playback stops at the end of the queue

## Build with GitHub Actions
Push the project to GitHub. The included workflow builds a debug APK using JDK 17 and Gradle 8.7.
